The argument rests on these

Birgitta Böckeler — Maintainability sensors for coding agents
https://martinfowler.com/articles/sensors-for-coding-agents.html
The word sensor, the computational/inferential distinction, and the finding this whole talk
is built on: asking an agent via a markdown guide to check its sensors proved unreliable.

Ivett Ördög — habit-hooks
https://github.com/habit-hooks/habit-hooks
Pairing a coaching guide with each finding instead of a bare metric. Also the story that
gives the talk its sharpest slide: given only a threshold, an agent refactors until the
linter goes quiet and the evidence goes quiet with it.

Liina Suoniemi — prompt-vs-metric-eval
https://github.com/LiinaSuoniemi/prompt-vs-metric-eval
That coaching measurably works on the complexity smell, on Sonnet. Use the per-smell figures, never the pooled ones — the
pooled number is inflated by a blind-except arm that scored zero by construction.

Giles Edwards-Alexander — The economic benefit of refactoring
https://martinfowler.com/articles/exploring-gen-ai/refactoring-economic-benefit.html
159,564 → 27,360 input tokens for the identical change, with line count and output tokens
held flat. The price tag on the whole argument.

Martin Fowler — Design Stamina Hypothesis
https://martinfowler.com/bliki/DesignStaminaHypothesis.html
Neglect design and every feature costs more than the one before it. Agents write faster, so
the payoff line arrives sooner.

Michael Feathers — The Deep Synergy Between Testability and Good Design (talk)
https://www.youtube.com/watch?v=4cVZvoFGJTU
Why a test that reads as a specification is a design signal, not a testing preference.

Also named on a slide

Kent Beck — "I'm not a great developer. I'm a good developer with great habits."
Widely quoted; the habits argument runs through Extreme Programming Explained (Addison-Wesley).
→ needs a citation decision: quote the book, or cite the talk it was said in. See open items.

Peter Naur — Programming as Theory Building (1985)
https://pages.cs.wisc.edu/~remzi/Naur.pdf
Understanding lives in people, not artifacts — the spine of the closing beat.

Blaise Pascal — Lettres provinciales, Letter XVI (1657)
"Je n'ai fait celle-ci plus longue que parce que je n'ai pas eu le loisir de la faire plus courte."
The line the deck quotes about the length of the coaching guides. Routinely attributed to Mark Twain,
and also to Cicero, Locke, Johnson, Goethe and Woodrow Wilson; no primary source exists for any of
them. Pascal's is the documented original. The slide names both the real source and the common
misattribution, on the grounds that a talk about verifying your claims should not open a caveat
slide with an unverified one.
